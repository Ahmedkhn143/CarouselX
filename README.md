# CarouselX

> AI-powered LinkedIn & Instagram Carousel Generator built with **React 19**, **Vite**, **TypeScript**, **Fabric.js**, and **Claude AI**.

## 🚀 Features
- **AI Content Generator**: Generate 6, 8, or 10-slide carousels tailored to your audience using Anthropic's Claude 3.5 Sonnet.
- **Tone & Language Options**: English (Professional), Roman Urdu / Hinglish (Conversational), and Bilingual.
- **Interactive Canvas**: Drag, drop, scale, and edit slide text directly on the canvas using Fabric.js.
- **Curated Templates**: Modern, Minimal, Bold, Gradient, and localized styles.
- **Platform Presets**: LinkedIn (4:5 portrait), Instagram (1:1 square), and Twitter (16:9 landscape).
- **Export Ready**: Multi-page PDF export via `jsPDF` ready for LinkedIn Document Carousels, plus single slide PNG downloads.
- **Draft Persistence**: Auto-saves your drafts to browser local storage.

## 🛠️ Tech Stack
- **Framework**: React 19 + Vite 8
- **Language**: TypeScript
- **Canvas Engine**: Fabric.js 5.5
- **PDF Export**: jsPDF 4.2
- **Styling**: Vanilla CSS Design System with custom design tokens

## 📦 Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm

### Installation
```bash
npm install
```

### Run Locally
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```
